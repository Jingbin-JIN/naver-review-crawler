# 네이버 플레이스 방문자 리뷰 수집기 (연구용 v0.2)

(한국어 사용 안내. 영문 개요는 [README.md](README.md))

팀 시트에 있는 업체의 네이버 플레이스 방문자 리뷰와 업체 정보(전체 리뷰 수, 쿠폰 수)를 모아 엑셀로 정리합니다. 대가성 리뷰 연구의 리뷰 수집용입니다.

**실제 네이버로 확인함 (2026-10-09):** 팀 시트의 업체 29곳을 업체명으로 모두 찾았고, 업체마다 최신 리뷰 10개씩 290건을 수집했습니다. 닉네임·사용자 ID·블로그 작성자 정보는 결과 파일 어디에도 남지 않는 것을 확인했습니다.

## 준비 (처음 한 번)

**맥.** 터미널에서 이 폴더로 이동해 준비 스크립트를 실행합니다.

```
cd ~/Projects/review_crawler
bash setup_mac.sh
```

마지막에 `OK`와 `준비 완료`가 나오면 끝입니다. 이후 명령은 모두 `.venv/bin/python`으로 실행합니다.

**윈도우.** Python 3.9 이상에서 `python -m pip install -r requirements.txt` → `python -m playwright install chromium` → `python -m unittest`. 아래 명령의 `.venv/bin/python`은 `python`으로 바꿉니다.

## 수집

**팀 시트로 (기본).** 구글 시트를 파일 → 다운로드 → Microsoft Excel(.xlsx)로 받은 뒤:

```
.venv/bin/python crawl.py run --input "받은 파일.xlsx" --sheet 팀원A
```

- `--sheet`에는 탭 이름을 넣습니다.
- `플레이스 링크` 열이 있으면 링크로, 없으면 **업체명으로 네이버에서 찾습니다.** 이름이 네이버와 정확히 같은 곳만 고르고(띄어쓰기 무시), 비슷하기만 한 곳은 건너뜁니다. '장소' 열(혜화=1, 신촌=2, 강남=3, 종로=4)이 있으면 그 근처를 먼저 찾습니다.
- 처음엔 `--limit 5`로 앞의 5곳만 해 볼 수 있습니다. 29곳 전체는 4~5분 걸립니다.

**링크만으로.** `.venv/bin/python crawl.py run --place "링크1" --place "링크2"`

**한 곳만 자세히 확인.** `.venv/bin/python crawl.py probe --place "링크"` → 구조 요약이 화면과 `data/probe/`에 저장됩니다.

## 결과 (`data` 폴더)

- `reviews_날짜_시각.xlsx`: 이번 실행분. **'리뷰' 시트**(리뷰 한 줄씩)와 **'업체' 시트**(업체별 찾은 방법·네이버 업체명·주소·전체 리뷰 수·쿠폰 수·결과).
- `reviews.csv`: 지금까지 모은 리뷰 전체. 같은 리뷰는 한 번만 저장됩니다.
- `run_log.csv`: 실행할 때마다 업체별 결과가 쌓입니다. 날마다 돌리면 업체별 '전체 리뷰 수'와 '쿠폰 수'의 일별 변화가 남습니다.
- `raw/날짜/플레이스ID.json`: 원본 데이터(개인정보를 지운 것). 구조 확인용입니다.
- 리뷰 전체를 엑셀 하나로 보려면 `.venv/bin/python crawl.py export`.

## 결과 열 (리뷰 시트)

| 열 | 뜻 |
|---|---|
| 작성일 / 방문일 | 리뷰를 쓴 날, 방문한 날 (원문 표기는 '작성일(원문)') |
| 별점 | 리뷰 데이터에 들어 있는 별점 |
| 본문 / 본문 길이 | 리뷰 글과 글자 수 |
| 사진·영상 수 | 리뷰에 붙은 사진·영상 개수 (영수증 사진 제외) |
| 인증 수단 | 영수증, 결제내역, 예약 |
| 방문 차수 / 선택 키워드 | 몇 번째 방문인지, 고른 키워드 |
| 리뷰어 리뷰 수 / 사진 수 | 리뷰어가 지금까지 쓴 리뷰·사진 수 (숫자만) |
| 이벤트 언급(확인 필요) | 본문에 '리뷰 이벤트', '리뷰 쓰고 ○○ 받았어요' 같은 표현이 있으면 1. ground truth의 '확실한 대가성' 후보이며 사람이 한 번 더 확인합니다 |
| 서비스 언급(약한 신호) | '서비스로 ○○ 주셨어요' 같은 표현이면 1. 이벤트와 무관할 수 있습니다 |
| 리뷰어 구분값 | `REVIEW_SALT`를 설정했을 때만 채워집니다 (아래 참고) |

**쿠폰 수(업체 시트):** 업체 페이지에 걸린 쿠폰 개수입니다. 리뷰 이벤트 쿠폰이 포함되지만, 쿠폰 종류와 '오늘 마감' 여부는 별도 예약 페이지에 있어 수집하지 않습니다.

## 수집 방식과 한계

- **기본(http) 엔진:** 브라우저 없이 리뷰 페이지 HTML에 들어 있는 데이터를 읽습니다. 업체마다 **최신 리뷰 10개**를 가져옵니다. 하루 리뷰가 10개를 넘는 곳은 매일 돌려도 일부가 빠질 수 있습니다.
- **브라우저 엔진(`--engine browser`):** 브라우저로 열어 '더보기'를 눌러 더 가져오려고 시도합니다. 실제 네이버에서 더보기가 되는지는 아직 확인하지 못했습니다.
- 네이버가 자동 접속 확인(캡차)을 요구하면 해당 업체는 `error`(captcha)로 남습니다. 캡차를 우회하지 않고, 시간을 두고 다시 실행합니다.

## 수집 원칙

- 추적 중인 업체만, 하루 한 번 수집합니다. 업체 사이에 4~8초 쉬는 것이 기본값이며 줄이지 않습니다.
- 닉네임, 프로필 사진·링크, 사용자 ID, 블로그 작성자 이름·주소는 저장하지 않습니다. 원본 JSON과 probe 요약도 지운 뒤 저장합니다.
- 같은 사람이 쓴 리뷰를 구분해야 할 때만 환경변수 `REVIEW_SALT`에 비밀 문자열을 넣습니다. 그러면 원래 ID를 알 수 없는 12자리 구분값만 저장됩니다. 이 문자열은 팀 밖에 공유하지 않습니다.
- 네이버 이용약관은 자동 수집을 제한합니다. 연구 목적의 소량 수집이며, 범위는 교수님·연구실 기준을 따릅니다.

## 문제 해결

- **name_not_found.** 시트의 업체명이 네이버 이름과 정확히 같지 않은 경우입니다. 시트에 `플레이스 링크` 열을 만들어 그 업체의 공유 링크를 넣습니다.
- **unresolved_link.** 링크에서 플레이스 ID를 찾지 못한 경우입니다. 공유 링크를 다시 붙여넣거나 플레이스 주소(`m.place.naver.com/...`)를 넣습니다.
- **error / no_reviews.** `probe`로 그 업체를 확인합니다. 구조가 바뀌었으면 `naver_reviews/extract.py`의 `REVIEW_TYPENAMES`·`FIELD_CANDIDATES`를 맞춥니다.
- **'시트가 없습니다'.** `--sheet`의 탭 이름을 확인합니다. 오류 문구에 있는 탭 목록 중 하나를 그대로 씁니다.

## 검증 상태

- **실제 네이버로 확인한 것 (2026-10-09):** 업체명 검색(29/29 정확히 일치), 리뷰 페이지 데이터 구조, 리뷰 필드(작성일·방문일·별점·본문·사진 수·인증 수단·방문 차수·키워드·리뷰어 통계), 업체 정보(전체 리뷰 수·쿠폰 수), 개인정보 제거.
- **테스트:** `python -m unittest` (50개). 실제 구조를 본뜬 가짜 데이터로 하는 회귀 테스트, 로컬 가짜 서버로 하는 전체 흐름(http·브라우저 엔진) 포함.
- **아직 확인하지 못한 것:** 브라우저 엔진의 '더보기'가 실제 네이버에서 되는지.

## 구조

```
setup_mac.sh              맥 준비 (가상환경·설치·테스트)
crawl.py                  실행 명령 (run, probe, export)
naver_reviews/web.py      기본 엔진: 페이지 HTML 읽기, 업체명 검색
naver_reviews/browser.py  브라우저 엔진: 페이지 열기, 더보기, 응답 수집
naver_reviews/extract.py  리뷰·업체 정보 정리, 개인정보 제거, 이벤트 언급 표시
naver_reviews/ids.py      링크·공유 문구 → 플레이스 ID, 업체명
naver_reviews/places.py   팀 시트(xlsx)·CSV 읽기
naver_reviews/store.py    CSV 누적, 엑셀 저장
naver_reviews/net.py      HTTP 요청 (맥 인증서 문제 대비)
tests/                    테스트
```
